# t1_task（M6，目前只有包壳）

> 目录已按 horkin-core 重排成仓库根下的同名目录，不再使用 `src/t1_*` 包。文中若还出现旧路径，以 README 的目录表和 `docs/PROGRESS.md` 为准。


任务层：用行为树把导航、准备动作、清扫、收尾串起来。实现"边走边准备、到达即开工"。命名空间 `T1::task`。

## 并行准备的时间计算

- 设导航预计剩余时间 \(T_{nav}\)（Nav2 反馈的剩余距离 / 平均速度），准备动作总时长 \(T_{prep}\)（离开收纳位 + 取刷头 + 移到预清扫位，时长由动作库给出）。
- 当 \(T_{nav} \le T_{prep} + T_{margin}\) 时开始准备动作；底盘行进中由 WBC 补偿底盘运动。
- **约束**：取放刷头需要与刷头座精确对位，只能在底盘静止时进行。若刷头座在机器人身上，可以全程边走边做；若在墙上，则取刷头必须在出发前完成，行进中只做"离开收纳位、移到预清扫位"。
- 验收：到达后到开始清扫的等待 < 1 s。
